An editor is a useful reference for a technical blog. Most of the screen is devoted to text, a small area helps you navigate, and color carries meaning.

## Color with a job

The notebook borrows its warm charcoal surfaces and vivid accents from [Monokai Pro](https://monokai.pro/). Green marks navigation and links; purple, cyan, and amber distinguish topics and syntax.

The restrained spacing and reading focus take cues from [Obsidian Minimal](https://minimal.guide/).

## Let the text breathe

Reading is easier when the line length is bounded and paragraphs have room. A sidebar can be useful on a wide display, but it shouldn't compete with a note on a phone.

| Element      | Purpose            |
| ------------ | ------------------ |
| Explorer     | Find a topic       |
| Search       | Retrieve a thought |
| Reading pane | Stay with one idea |
| Theme switch | Adapt to the room  |

## An interface you can leave

The pages remain readable without JavaScript. The feed works in a reader. A URL can be bookmarked. These are small choices, but together they make the site less demanding of its visitors.
